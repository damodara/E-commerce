
# E-commerce (ООП, учебный проект)

Небольшой учебный проект для практики основ ООП на Python: модели товаров и категорий с наследованием, магическими методами и защитой данных.

## Структура проекта

### Основные классы
- `src/product.py` — базовый класс `Product` с полями `name`, `description`, `price`, `quantity`
- `src/category.py` — класс `Category` с полями `name`, `description`, `products` и атрибутами класса
- `src/smartphone_product.py` — класс `Smartphone` (наследник `Product`)
- `src/lawn_grass_product.py` — класс `LawnGrass` (наследник `Product`)

### Дополнительные файлы
- `main.py` — пример использования всех классов
- `tests/` — тесты `pytest`, `conftest.py` содержит фикстуры
- `pyproject.toml` — конфигурация проекта и зависимости

## Классы и их функциональность

### Product (базовый класс)
- **Поля**: `name`, `description`, `_price` (приватный), `quantity`
- **Геттер/сеттер**: `price` с проверкой положительности
- **Магические методы**:
  - `__str__()` — строковое представление
  - `__add__()` — сложение только объектов одинакового класса
- **Класс-методы**:
  - `new_product()` — создание из словаря
  - `new_product_with_duplicate_check()` — создание с проверкой дубликатов

### Smartphone (наследник Product)
- **Дополнительные поля**: `efficiency`, `model`, `memory`, `color`
- Наследует всю функциональность `Product`

### LawnGrass (наследник Product)
- **Дополнительные поля**: `country`, `germination_period`, `color`
- Наследует всю функциональность `Product`

### Category
- **Поля**: `name`, `description`, `_products` (приватный список)
- **Атрибуты класса**: `category_count`, `product_count` (автоматически обновляются)
- **Методы**:
  - `add_product()` — добавление с проверкой типа через `isinstance()`
  - `products` (property) — геттер для строкового представления товаров
- **Магические методы**:
  - `__str__()` — строковое представление с подсчетом общего количества товаров
- **Итератор**: `CategoryIterator` для перебора товаров в цикле

## Основные возможности

### 1. Создание товаров
```python
# Базовый товар
product = Product("Товар", "Описание", 100.0, 5)

# Смартфон
smartphone = Smartphone("iPhone 15", "Описание", 100000.0, 3, 95.5, "15", 256, "Черный")

# Газонная трава
grass = LawnGrass("Трава", "Описание", 500.0, 10, "Россия", "7 дней", "Зеленый")
```

### 2. Работа с категориями
```python
# Создание категории
category = Category("Смартфоны", "Описание")

# Добавление товаров
category.add_product(smartphone1)
category.add_product(smartphone2)

# Получение списка товаров
print(category.products)
```

### 3. Магические методы
```python
# Строковое представление
print(smartphone)  # "iPhone 15, 100000.0 руб. Остаток: 3 шт."

# Сложение товаров (только одинаковых классов)
total_value = smartphone1 + smartphone2  # OK
# smartphone1 + grass  # TypeError
```

### 4. Защита от некорректных данных
```python
# Проверка типа при добавлении в категорию
category.add_product(smartphone)  # OK
# category.add_product("строка")  # TypeError

# Проверка цены
smartphone.price = 50000.0  # OK
# smartphone.price = -1000.0  # Выводит сообщение об ошибке
```

## Архитектурные решения

### Наследование
- `Smartphone` и `LawnGrass` наследуют от `Product`
- Переиспользование кода и полиморфизм

### Инкапсуляция
- Приватные атрибуты (`_price`, `_products`)
- Геттеры и сеттеры с проверками
- Защита от некорректных данных

### Полиморфизм
- Единый интерфейс для всех товаров
- Переопределение методов в наследниках

### Атрибуты класса
- Общие счетчики для всех экземпляров
- Автоматическое обновление при создании объектов
