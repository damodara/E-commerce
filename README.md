
# E-commerce (ООП, учебный проект)

Небольшой учебный проект для практики основ ООП на Python: модели товаров и категорий с наследованием, абстрактными классами, миксинами и защитой данных.

## Структура проекта

### Основные классы
- `src/base_product.py` — абстрактный базовый класс `BaseProduct`
- `src/product.py` — класс `Product` (наследует от `BaseProduct` и `LoggingMixin`)
- `src/category.py` — класс `Category` с полями `name`, `description`, `products` и атрибутами класса
- `src/smartphone_product.py` — класс `Smartphone` (наследник `Product`)
- `src/lawn_grass_product.py` — класс `LawnGrass` (наследник `Product`)
- `src/logging_mixin.py` — миксин `LoggingMixin` для логирования создания объектов
- `src/order.py` — класс `Order` для управления заказами

### Дополнительные файлы
- `main.py` — пример использования всех классов
- `tests/` — тесты `pytest`, `conftest.py` содержит фикстуры
- `pyproject.toml` — конфигурация проекта и зависимости

## Архитектура классов

### Цепочка наследования
```
BaseProduct (абстрактный)
    ↓
Product (конкретный класс + LoggingMixin)
    ↓
Smartphone / LawnGrass (специализированные классы)
```

### BaseProduct (абстрактный базовый класс)
- **Абстрактные методы**:
  - `__init__()` — инициализация продукта
  - `get_total_value()` — получение общей стоимости
  - `__str__()` — строковое представление
- **Конкретные методы**:
  - `is_available()` — проверка доступности товара
  - `get_info()` — получение информации о товаре

### Product (конкретный класс)
- **Наследование**: `BaseProduct` + `LoggingMixin`
- **Поля**: `name`, `description`, `_price` (приватный), `quantity`
- **Геттер/сеттер**: `price` с проверкой положительности
- **Магические методы**:
  - `__str__()` — строковое представление
  - `__add__()` — сложение только объектов одинакового класса
  - `__repr__()` — представление для отладки (из миксина)
- **Класс-методы**:
  - `new_product()` — создание из словаря
  - `new_product_with_duplicate_check()` — создание с проверкой дубликатов

### LoggingMixin (миксин)
- **Функциональность**: автоматическое логирование создания объектов
- **Методы**:
  - `__init__()` — инициализация с логированием
  - `_log_creation()` — вывод информации о создании объекта
  - `_get_init_args()` — получение аргументов для логирования
  - `__repr__()` — строковое представление для отладки

### Smartphone (наследник Product)
- **Дополнительные поля**: `efficiency`, `model`, `memory`, `color`
- **Методы**:
  - `get_specifications()` — получение технических характеристик
  - `_get_init_args()` — переопределение для корректного логирования

### LawnGrass (наследник Product)
- **Дополнительные поля**: `country`, `germination_period`, `color`
- **Методы**:
  - `get_growing_info()` — получение информации о выращивании
  - `_get_init_args()` — переопределение для корректного логирования

### Category
- **Поля**: `name`, `description`, `_products` (приватный список)
- **Атрибуты класса**: `category_count`, `product_count` (автоматически обновляются)
- **Методы**:
  - `add_product()` — добавление с проверкой типа через `isinstance()`
  - `products` (property) — геттер для строкового представления товаров
- **Магические методы**:
  - `__str__()` — строковое представление с подсчетом общего количества товаров
- **Итератор**: `CategoryIterator` для перебора товаров в цикле

### Order (дополнительно)
- **Наследование**: `BaseProduct`
- **Поля**: `product`, `quantity`, `name`, `description`, `_price`
- **Методы**:
  - `get_total_value()` — общая стоимость заказа
  - `is_available()` — проверка возможности выполнения заказа
  - `execute()` — выполнение заказа (уменьшение количества на складе)

## Основные возможности

### 1. Создание товаров с автоматическим логированием
```python
# Базовый товар (выводит: Product('Товар', 'Описание', 100.0, 5))
product = Product("Товар", "Описание", 100.0, 5)

# Смартфон (выводит: Smartphone('iPhone 15', 'Описание', 100000.0, 3, 95.5, '15', 256, 'Черный'))
smartphone = Smartphone("iPhone 15", "Описание", 100000.0, 3, 95.5, "15", 256, "Черный")

# Газонная трава (выводит: LawnGrass('Трава', 'Описание', 500.0, 10, 'Россия', '7 дней', 'Зеленый'))
grass = LawnGrass("Трава", "Описание", 500.0, 10, "Россия", "7 дней", "Зеленый")
```

### 2. Работа с абстрактным базовым классом
```python
# Проверка доступности
print(product.is_available())  # True

# Получение общей стоимости
print(product.get_total_value())  # 500.0

# Получение полной информации
info = product.get_info()
print(info)  # {'name': 'Товар', 'description': 'Описание', ...}
```

### 3. Работа с категориями
```python
# Создание категории
category = Category("Смартфоны", "Описание")

# Добавление товаров
category.add_product(smartphone1)
category.add_product(smartphone2)

# Получение списка товаров
print(category.products)
```

### 4. Магические методы и полиморфизм
```python
# Строковое представление
print(smartphone)  # "iPhone 15, 100000.0 руб. Остаток: 3 шт."

# Сложение товаров (только одинаковых классов)
total_value = smartphone1 + smartphone2  # OK
# smartphone1 + grass  # TypeError

# Представление для отладки
print(repr(smartphone))  # Smartphone('iPhone 15', 'Описание', ...)
```

### 5. Защита от некорректных данных
```python
# Проверка типа при добавлении в категорию
category.add_product(smartphone)  # OK
# category.add_product("строка")  # TypeError

# Проверка цены
smartphone.price = 50000.0  # OK
# smartphone.price = -1000.0  # Выводит сообщение об ошибке
```

## Архитектурные решения

### Наследование
- `Smartphone` и `LawnGrass` наследуют от `Product`
- Переиспользование кода и полиморфизм

### Инкапсуляция
- Приватные атрибуты (`_price`, `_products`)
- Геттеры и сеттеры с проверками
- Защита от некорректных данных

### Полиморфизм
- Единый интерфейс для всех товаров
- Переопределение методов в наследниках

### Атрибуты класса
- Общие счетчики для всех экземпляров
- Автоматическое обновление при создании объектов
